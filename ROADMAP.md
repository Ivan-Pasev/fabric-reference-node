# Roadmap

## R0 — Public genesis

- installable Python package
- public schemas and OpenAPI surface
- synthetic governed-decision example
- local SQLite persistence
- retraction / rollback semantics
- CI and reproducible tests
- explicit claim and security boundaries

## R1 — Interoperability

- policy-as-code adapter (OPA-compatible first target)
- verifiable credential / institutional identity adapter
- MCP/A2A integration examples
- provenance export mapping
- stable adapter interface

## R2 — Security and assurance

- formal threat model
- fuzzing and malformed-input campaigns
- authenticated API profile
- cryptographic receipt profile
- dependency/supply-chain hardening
- independent security review

## R3 — External adoption evidence

- independent reproduction
- first external design partner
- baseline decision-reconstruction measurement
- public integration case
- issue/feedback loop from non-maintainers

## R4 — Federation

- multi-node transfer receipts
- semantic-loss declarations
- sovereign trust-domain boundaries
- federation conformance suite

## R5 — Formalization

- mechanized core preservation lemmas
- executable/formal correspondence tests
- explicit proof receipts without automatic authority promotion
