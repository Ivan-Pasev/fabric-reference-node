# Claim Boundary

Fabric Reference Node is an open-source **reference implementation**, not a certification system.

## Supported by current local executable evidence

The repository is designed and locally tested to demonstrate deterministic handling of evidence, declared policy, institutional authority, invariant results, machine outcomes, human decisions, traces, receipts, persistent state, retraction overlays, and rollback history.

## Not implied

Nothing in this repository by itself establishes:

- legal or regulatory compliance;
- formal proof of system-wide safety or correctness;
- scientific truth of claims stored in the node;
- production security or penetration-test assurance;
- fairness, bias elimination, or ethical correctness;
- identity authenticity beyond the configured adapter;
- organizational authorization beyond the supplied authority record;
- production availability, disaster recovery, or scale;
- Digital Fabrica Theory as an accepted scientific theory.

## Core non-promotion rules

```text
machine PASS != institutional APPROVE
execution != proof
signature != competence
storage != provenance
projection != semantic equivalence
rollback != historical erasure
local persistence != production durability
```

Every new adapter or capability should preserve these boundaries or document an explicit stronger evidence basis.
