# Funding the Open-Source Core

Fabric Reference Node is intentionally not tailored to one funder.

The invariant is:

> **One repository, one public technical truth, multiple non-conflicting evidence-producing work packages.**

Suitable funding can support different public workstreams without changing the project's semantics:

- maintainer runway and documentation;
- interoperability and open standards;
- security hardening and independent audit;
- formal methods and reproducibility;
- external integrations and adoption;
- long-term maintenance and contributor infrastructure.

Potential channels include open-source fellowships, digital-public-infrastructure grants, security grants, GitHub Sponsors, sponsored integrations, institutional design partnerships, and later paid deployment/support around the open core.

Funding never purchases claim promotion, validator authority, or scientific/formal status.
